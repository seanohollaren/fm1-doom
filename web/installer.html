Doom for the FM-1

The first level of Doom on the synth's own screen, keys and speaker. It installs from this page over USB.

1Game data

The Doom engine is free software. The game's levels, pictures and sounds are not, so this page doesn't carry them. You bring the game file, and the page cuts it down to fit the FM-1 here in your browser. The file is not uploaded anywhere.

or drop the file here

DOOM1.WAD is the free shareware release of Doom (version 1.9, 4.2 MB): about the file. DOOM.WAD from the full game should work too, but only the shareware file has been tested.

  • Connect the FM-1 straight to this computer by USB, no hub, and switch it on.
  • Use Chrome or Edge on a computer, and close other apps and tabs that use MIDI.
  • Leave the cable and this page alone until it says Done.

What this changes on the FM-1
  • It replaces the synth firmware. The FM-1 is a Doom machine until you install a synth firmware again.
  • It overwrites the part of the memory where Felucca keeps saved projects and samples. Back those up from Felucca first if you want them.
  • Presets saved by M-VAVE's original firmware are not touched.
  • The FM-1's boot code is never written. Holding HOME while switching on always brings up a screen that waits for an install instead of starting the game.

This is experimental firmware, tested on one FM-1. Use it at your own risk.

Controls
  • Move with the low keys: G and B turn, the black keys between them go forward, A goes back, F and C step sideways, F♯ runs.
  • At the top of the keyboard: E or F fires, D or the top G opens doors and presses switches.
  • REC also fires. PLAY is Enter, HOME opens the menu, OCT− and OCT+ change weapon.
  • SCL changes the picture shape, ENV shows the frame rate.
If the screen shows a plain colour
  • Blue: the firmware is waiting for game data. Press Install on this page.
  • Cyan: you held HOME while switching on. The FM-1 waits for an install instead of starting the game. Use this if the page can't find the FM-1 while Doom is running.
  • Amber: the game failed to start. Press Install again, or hold PLAY for two seconds to try the game once more.
  • Red or magenta: the game stopped. The FM-1 restarts by itself.
  • Dark, after three minutes on one of these screens with no computer talking to it: switch the FM-1 off and on.
Going back to a synth firmware

Open Felucca's installer and install it as on any FM-1. From Felucca you can return to M-VAVE's original firmware the usual way.
